# Paper Notes

## CRAG

CRAG argues that RAG systems fail when retrieval returns irrelevant or misleading documents. The project maps this into a retrieval evaluator and three actions: Correct, Incorrect, and Ambiguous.

## Adaptive-RAG

Adaptive-RAG routes queries by complexity. This project implements a practical heuristic router that chooses simple, multi-hop, long-context, or web-needed query handling.

## RAPTOR

RAPTOR improves retrieval by organizing text through summaries. This project creates document and section summaries and includes them for long-context queries.

## ARES/RAGAS

ARES and RAGAS emphasize measuring RAG quality. This project reports context relevance, answer faithfulness, answer relevance, citation coverage, and latency.
